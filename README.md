# JobSearcher — Native macOS app

This branch contains the **Swift/Xcode native macOS app**, migrated from `Alehaaaa/JobUI` with its original Git history preserved. The existing `JobUI.xcodeproj` and Swift module names remain intact for build and installation compatibility.

## Getting started

```bash
git clone --branch mac https://github.com/Alehaaaa/JobSearcher.git
cd JobSearcher
open JobUI.xcodeproj
```

## Other branches

- [`main`](https://github.com/Alehaaaa/JobSearcher/tree/main): Python/Maya job browser and studio configuration
- [`web-app`](https://github.com/Alehaaaa/JobSearcher/tree/web-app): Editable Vite/React website
- [`github-pages`](https://github.com/Alehaaaa/JobSearcher/tree/github-pages): Compiled, published browser site at https://alehaaaa.github.io/JobSearcher/

The former `Alehaaaa/JobUI` repository is only a historical backup. Develop and commit new work to `Alehaaaa/JobSearcher`.
